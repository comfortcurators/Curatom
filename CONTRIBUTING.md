# Contributing

Issue reports and security feedback are welcome through the publisher's
official channels. Code contributions are not accepted automatically.

Curatom Enterprise uses an AGPL/commercial dual-license model. To preserve the
publisher's ability to offer both licensing paths, Comfort Curators Private
Limited must confirm the applicable contributor agreement in writing before a
code contribution is submitted or accepted. Opening a pull request by itself
does not create a contributor agreement or grant the publisher commercial
relicensing rights.

Do not include third-party code, confidential information, personal data, or
material you are not authorized to contribute.
